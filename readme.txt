A toy plugin where DiluxOne's shared workflows are proved end to end. Not published anywhere.

== Description ==

It greets someone, counts words, and keeps one setting. Its bugs, its features and its security patches exist to be found, fixed and released by the organisation's workflows before they reach a real plugin.

In a post, the shortcode `[dxsb_greet name="Ada"]` shows the greeting for that name: Hello, Ada!
